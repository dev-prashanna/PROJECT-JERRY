PROJECT JERRY
=============

Planning to build a pet robot capable of understanding and learning the
environment around it like a lively creature.

A full-stack robotics workspace: ESP32 firmware for the body (camera
streaming, motor drive, ultrasonics, servos) and a local-first Python
perception and dialogue brain (Whisper STT, LLM intent routing,
Moondream-2 VLM, Depth Anything V2 monocular depth, Kokoro-82M TTS)
orchestrated by a bounded state machine and presented through a PySide6
dashboard.
